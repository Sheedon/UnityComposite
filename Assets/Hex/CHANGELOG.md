# Changelog

## [0.2.0] - 2026-08-14

- Added mutable finite regions with duplicate-safe membership.
- Added hexagon, odd-q rectangle, square, geometric circle, axial parallelogram, and irregular region builders.
- Added generic coordinate data layers constrained by a live region.
- Added Map EditMode coverage, including region remove/re-add behavior.

## [0.1.0] - 2026-08-13

- Added the UPM package and runtime/test assembly definitions.
- Added axial coordinates and stable flat-top directions.
- Added neighbors, distance, range, ring, and spiral topology operations.
- Added axial rounding and line generation.
- Added Unity-independent point and flat-top layout conversion.
- Added EditMode coverage for the Core API.
